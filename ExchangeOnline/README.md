# Exchange Online Scripts

Microsoft Exchange Online reporting and auditing scripts.

## Scripts

### Export-MailboxReport.ps1
Mailbox inventory export.

### Get-DistributionGroups.ps1
Distribution Group report.

### Get-ExternalMailToDG.ps1
Checks distribution groups allowing external senders.

### Get-MailboxForwardingAudit.ps1
Detects mailboxes with forwarding enabled.

### Get-MailboxPermissions.ps1
Exports mailbox permissions.

### Get-MailboxSizeReport.ps1
Mailbox size report.

### Get-SharedMailboxReport.ps1
Shared mailbox inventory.

### Get-UnusedSharedMailboxes.ps1
Detects inactive shared mailboxes.
